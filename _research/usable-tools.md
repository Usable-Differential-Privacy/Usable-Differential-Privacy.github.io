Differential privacy tools promise to make privacy-preserving analysis more accessible, but their APIs, documentation, and workflows can still create significant barriers for data practitioners.

We study how practitioners learn and apply differential privacy, where existing tools cause confusion, and how interfaces and documentation can better support sound implementation.

This work informs evidence-based recommendations for designing differential privacy tools that practitioners can use with greater confidence.
